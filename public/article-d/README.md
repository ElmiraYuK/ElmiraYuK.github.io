# Working project — unpublished preprint

Author manuscript dated 22 November 2026, built from the root main.tex of the author-provided Overleaf export. The manuscript PDF is available on the project page.

The simulator is an illustrative finite network. Its diffusion path is computed with Euler–Maruyama; finite-sample Wasserstein estimates do not prove convergence. See the article and the page for precise assumptions.

Run a local HTTP server in this directory to enable the web worker. Routing matrices are read in the browser.
